# Bienvenido a nuestro Miniproyecto Sección 9

Autores: María Clara Ávila Chinchia, David Alejandro Ibáñez Barrios y Mateo José Giraldo Castillo

En este proyecto abordamos la predicción del riesgo crediticio con el uso de modelos de clasificación al dataset proporcionado. El modelo seleccionado fue un Random Forest Classifier, optimizado mediante búsqueda de hiperparámetros en scikit-learn y configuraciones manuales en PySpark. 

Así, realizamos una comparación entre ambos enfoques, mostrando que mientras scikit-learn resulta eficiente en entornos locales con subconjuntos de datos moderados, PySpark se presenta como una solución robusta para grandes volúmenes de información. Esta combinación de métricas permite obtener una visión integral del problema de predicción de incumplimiento crediticio.
